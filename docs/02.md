## 开篇：工具选错了，努力白费

我见过一类很典型的失败案例：

一个产品经理，读了很多 VibeCoding 的文章，热情高涨，某个周末花了整整一天，把七八个 AI 工具全装了一遍——Cursor 试了试，Copilot 也装了，又去注册了 Bolt 的账号，最后把 Claude Code 也跑了起来。折腾了一天，每个工具都浅尝辄止，脑子里全是各种界面和命令，最终什么都没有做出来。

第二天，他问我：**"我好像会用 AI 了，但又好像什么都不会。"**

这不是他的问题，是入门路径的问题。

AI 编程工具在 2024 到 2025 年经历了一次爆发，新工具的涌现速度远超普通人的消化能力。每个工具都在说自己是"最强 AI 编程助手"，每个工具都有让人印象深刻的 Demo 视频。但当你真正坐下来要做一件事的时候，反而不知道该打开哪个。

**这篇文章要解决的，正是这个问题。**

我们会把市面上主流的 AI 编程工具做一次系统梳理，让你看清楚它们各自的定位和适用场景。更重要的是，我们会手把手地把两款最具代表性的 CLI 工具——**Claude Code** 和 **OpenAI Codex CLI**——从零安装到跑通第一条命令，全程带你走一遍。

读完这篇，你会有一个清晰的答案：**我应该先学哪个工具，以及怎么装好它。**

### 为什么重点讲 CLI 工具，而不是 Cursor 这类图形界面工具？

这是个好问题，值得在开始之前回答清楚。

Cursor、Windsurf 这类工具确实更直观，有图形界面，看上去和普通编辑器没太大区别。对新手来说，上手摩擦最小。

但 CLI 工具（命令行工具）有一个独特的优势，这个优势在你真正开始做项目之后会越来越明显：

**它和你的项目是一体的。**

当你在项目目录里启动 Claude Code，它看到的是你的整个代码库，能读文件、写文件、执行命令、提交 Git。你和 AI 的对话，是在真实的项目上下文里发生的，不是在一个割裂的侧边栏里。这种"沉浸式"的协作方式，更接近 VibeCoding 的本质——你和 AI 共同操作一个真实的工程项目。

另外，CLI 工具在服务器上可以直接使用，对于需要自动化任务、远程部署的场景，是唯一的选择。

当然，这两类工具并不对立，很多人会同时用 Claude Code 和 Cursor，各取所长。我们后面的工具篇会专门讲 Cursor 的深度使用。

现在，先把 CLI 工具搞定。

## 一、工具全景：四类 AI 编程工具

市面上的 AI 编程工具眼花缭乱，先把它们按形态分类，心里就有底了。

### 1. IDE 插件型

嵌入你已经在用的编辑器（VS Code、JetBrains），以补全和 Chat 为核心能力。**优点**：接入成本低，不改变现有工作流。**缺点**：能力上限受宿主 IDE 限制。

代表：**GitHub Copilot**、**Codeium**、**Continue**

### 2. 独立 AI-First IDE 型

从零设计的编辑器，AI 能力深度集成，支持多文件联动编辑和 Agent 自主操作。**优点**：体验最流畅，功能最完整。**缺点**：需要切换工具习惯。

代表：**Cursor**、**Windsurf**

### 3. CLI（命令行）型

在终端里与 AI 对话，可以直接读写项目文件、执行命令、提交代码。**优点**：与 Git 工作流无缝结合，适合熟悉命令行的开发者，也适合服务器环境。**缺点**：没有图形界面，新手上手有一定门槛。

代表：**Claude Code**、**OpenAI Codex CLI**

### 4. 网页生成型

打开浏览器就能用，输入需求直接生成可运行的完整项目。**优点**：零安装门槛，适合快速原型。**缺点**：对大型项目的掌控力弱，代码难以接手深度定制。

代表：**Bolt.new**、**v0 by Vercel**、**Lovable**

## 二、主流工具横评

### 工具对比一览表

| 工具               | 形态     | 核心模型           | 免费额度      | 月费（付费版） | 最适合场景                      |
| ------------------ | -------- | ------------------ | ------------- | -------------- | ------------------------------- |
| **Claude Code**    | CLI      | Claude Opus/Sonnet | 按量计费      | $20（Max）     | 复杂项目、代码架构、团队协作    |
| **Codex CLI**      | CLI      | GPT-4o / o3        | 按量计费      | 按 Token 计费  | 快速脚本、OpenAI 生态用户       |
| **Cursor**         | AI IDE   | Claude + GPT-4o    | 2 周试用      | $20/月         | 日常开发主力工具                |
| **Windsurf**       | AI IDE   | Claude + 自研      | 有限免费      | $15/月         | 对话式开发体验                  |
| **GitHub Copilot** | IDE 插件 | GPT-4o             | 学生/开源免费 | $10/月         | 企业合规场景、现有 VS Code 用户 |
| **Bolt.new**       | 网页     | Claude Sonnet      | 每日限量      | $20/月         | 全栈原型，零基础快速启动        |
| **v0**             | 网页     | 自研               | 每日限量      | $20/月         | React 前端组件生成              |

### 如何选择第一款工具

- **完全没有编程基础** → 先从 **Bolt.new** 或 **v0** 起手，感受 AI 生成代码的过程，零安装
- **想系统学 VibeCoding、有一点命令行基础** → **Claude Code**，本课程的主力演示工具
- **已有编程基础、想提升日常开发效率** → **Cursor**，体验最完整的 AI IDE
- **公司有合规要求、不想换 VS Code** → **GitHub Copilot**

> 本文重点讲 **Claude Code** 和 **OpenAI Codex CLI** 的完整安装流程，因为这两款 CLI 工具代表了 VibeCoding 最核心的交互模式。

## 三、实战一：Claude Code 安装与配置

### 3.1 系统要求

| 项目     | 要求                                           |
| -------- | ---------------------------------------------- |
| 操作系统 | macOS 12+ / Ubuntu 20.04+ / Windows（需 WSL2） |
| Node.js  | **18.0 或以上**（推荐 20 LTS）                 |
| 网络     | 能访问 api.anthropic.com（国内需代理）         |

**检查 Node.js 版本：**

```bash
node --version
# 输出示例：v20.11.0
```

如果没有安装或版本过低，推荐用 [nvm](https://github.com/nvm-sh/nvm) 管理：

```bash
# 安装 nvm（macOS / Linux）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 重启终端后安装 Node.js 20
nvm install 20
nvm use 20
```

Windows 用户请先安装 WSL2，在 WSL 终端内按 Linux 方式操作。

---

### 3.2 安装 Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

安装完成后验证：

```bash
claude --version
# 输出示例：1.x.x
```

---

### 3.3 鉴权：申请 API Key 并登录

**第一步：申请 Anthropic API Key**

1. 访问 [console.anthropic.com](https://console.anthropic.com)，注册账号
2. 进入「API Keys」页面，点击「Create Key」
3. 复制生成的 Key（格式：`sk-ant-api03-...`），**只显示一次，务必保存**

> 费用说明：Anthropic 按 Token 计费，Claude Sonnet 约 $3/百万 input token。日常使用一个月通常不超过 $5。也可以订阅 **Claude Max**（$20/月），享受不限量使用。

**第二步：登录**

```bash
claude
```

首次运行会弹出引导流程，选择登录方式：

- **方式 A（推荐）：浏览器 OAuth 登录**  
  命令行会打开浏览器，用 Anthropic 账号授权，自动完成鉴权。

- **方式 B：直接设置环境变量**

```bash
export ANTHROPIC_API_KEY="sk-ant-api03-你的key"
```

写入 `~/.zshrc` 或 `~/.bashrc` 可以永久生效：

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-你的key"' >> ~/.zshrc
source ~/.zshrc
```

---

### 3.4 首次启动：认识交互界面

进入你的项目目录，启动 Claude Code：

```bash
cd ~/my-project
claude
```

你会看到如下界面：

```
╭─────────────────────────────────────╮
│  Claude Code  v1.x.x                │
│  Working directory: ~/my-project    │
╰─────────────────────────────────────╯

> _
```

这是一个交互式终端，直接用自然语言输入需求即可。几个快速体验的命令：

```
# 让 AI 了解你的项目
> 帮我分析一下这个项目的结构，告诉我主要模块是什么

# 让 AI 写代码
> 帮我写一个读取 CSV 文件并输出行数的 Python 脚本

# 让 AI 解释代码
> 解释一下 src/utils/parser.js 这个文件的作用

# 查看所有可用命令
> /help
```

**重要的内置命令：**

| 命令              | 作用                            |
| ----------------- | ------------------------------- |
| `/help`           | 显示所有命令                    |
| `/clear`          | 清除当前对话上下文              |
| `/model`          | 切换使用的 AI 模型              |
| `/cost`           | 查看本次会话消耗的 Token 和费用 |
| `Esc` 或 `Ctrl+C` | 中断当前 AI 操作                |

---

### 3.5 权限级别配置

Claude Code 在执行写文件、运行命令等操作时会请求你的审批。可以设置三种级别：

```bash
# 每次操作都询问（最安全，推荐新手）
claude --permission-mode ask

# 自动允许安全操作，高风险操作才询问（推荐日常使用）
claude --permission-mode auto

# 完全自动执行（谨慎使用）
claude --permission-mode full-auto
```

---

### 3.6 常见安装问题

**问题 1：`npm install` 报网络错误**

```bash
# 换用国内镜像
npm install -g @anthropic-ai/claude-code --registry https://registry.npmmirror.com
```

**问题 2：`command not found: claude`（macOS）**

npm 全局包路径没有加入 PATH，执行：

```bash
echo 'export PATH="$PATH:$(npm root -g)/../bin"' >> ~/.zshrc
source ~/.zshrc
```

**问题 3：Node 版本太低**

```bash
node --version  # 低于 v18
nvm install 20 && nvm use 20 && npm install -g @anthropic-ai/claude-code
```

**问题 4：国内访问 API 超时**

需要配置代理，在终端设置：

```bash
export HTTPS_PROXY=http://127.0.0.1:7890   # 替换为你的代理地址
```

## 四、实战二：OpenAI Codex CLI 安装与配置

### 4.1 Codex CLI 是什么

OpenAI Codex CLI（`@openai/codex`）是 OpenAI 于 2025 年发布的命令行 AI 编程工具，基于 GPT-4o 和 o3 模型。与 Claude Code 的定位相似，核心差异在于：

|                  | Claude Code                | OpenAI Codex CLI              |
| ---------------- | -------------------------- | ----------------------------- |
| **背后模型**     | Claude Opus / Sonnet       | GPT-4o / o3                   |
| **代码推理能力** | 长上下文、复杂架构分析更强 | o3 擅长算法和数学类问题       |
| **沙箱安全**     | 权限分级审批               | 内置沙箱隔离执行              |
| **适合场景**     | 大型项目、多文件联动       | 快速脚本、算法题、OpenAI 生态 |
| **计费方式**     | Anthropic API / Max 订阅   | OpenAI API 按量计费           |

两者可以并行安装，根据任务选择最合适的工具。

---

### 4.2 系统要求

与 Claude Code 相同：Node.js 18+ 即可。

---

### 4.3 安装 Codex CLI

```bash
npm install -g @openai/codex
```

验证安装：

```bash
codex --version
```

---

### 4.4 鉴权：申请 OpenAI API Key

**第一步：申请 API Key**

1. 访问 [platform.openai.com](https://platform.openai.com)，注册并登录
2. 进入「API Keys」，点击「Create new secret key」
3. 复制 Key（格式：`sk-proj-...`），保存好

> 费用说明：GPT-4o 约 $2.5/百万 input token，o3 约 $10/百万 input token。建议先充值 $5 体验，够用很长时间。

**第二步：配置 API Key**

推荐写入 shell 配置文件：

```bash
echo 'export OPENAI_API_KEY="sk-proj-你的key"' >> ~/.zshrc
source ~/.zshrc
```

也可以在项目目录创建 `.env` 文件（注意加入 `.gitignore`，不要提交到代码仓库）：

```bash
# .env
OPENAI_API_KEY=sk-proj-你的key
```

---

### 4.5 首次运行体验

Codex CLI 支持两种使用方式：

**方式一：单次任务（非交互式）**

```bash
# 直接在命令后跟需求描述
codex "帮我写一个统计当前目录下所有 .py 文件行数的脚本"
```

AI 会分析需求，生成代码，并询问你是否执行。

**方式二：交互式对话**

```bash
# 进入交互模式
codex
```

进入后和 Claude Code 类似，可以持续对话。

---

### 4.6 沙箱模式：安全执行 AI 生成的代码

Codex CLI 的一大特色是内置了**沙箱执行环境**，在 macOS 上基于 Apple Sandbox，在 Linux 上基于 Docker。

```bash
# 启用沙箱模式（推荐，AI 执行代码时在隔离环境中运行）
codex --sandbox "帮我写个脚本处理这些文件"

# 完全自动执行（AI 自主完成任务，不询问确认）
codex --full-auto "初始化一个 React 项目并安装依赖"

# 只建议、不执行（最安全，只看方案）
codex --suggest-only "怎么优化这段 SQL 查询"
```

**三种模式对比：**

| 模式       | 命令参数         | AI 操作                  | 适合场景             |
| ---------- | ---------------- | ------------------------ | -------------------- |
| 建议模式   | `--suggest-only` | 只输出代码，不执行       | 学习、理解方案       |
| 沙箱模式   | `--sandbox`      | 在隔离环境执行，每步确认 | 日常使用推荐         |
| 全自动模式 | `--full-auto`    | 自主完成任务             | 明确任务、信任 AI 时 |

---

### 4.7 常见配置问题

**问题 1：macOS 上沙箱功能报错**

```bash
# 确认 macOS 版本 12+，然后重试
sw_vers -productVersion
```

**问题 2：国内访问 OpenAI API 被拒**

OpenAI 屏蔽了部分中国 IP，需要代理：

```bash
export HTTPS_PROXY=http://127.0.0.1:7890
```

或者使用 OpenAI 兼容的国内中转 API，将 Base URL 指向中转服务：

```bash
export OPENAI_BASE_URL="https://你的中转服务地址/v1"
```

**问题 3：想用 o3 模型而不是默认的 GPT-4o**

```bash
codex --model o3 "帮我解决这道算法题"
```

## 五、两款工具的实际对比演示

同一个任务，分别用两个工具完成，感受差异：

**任务：** 写一个脚本，读取 `data.json`，找出所有 `status` 为 `"error"` 的记录，输出到 `errors.csv`

**Claude Code 操作：**

```bash
cd ~/project
claude
> 读取当前目录的 data.json，找出所有 status 字段为 "error" 的记录，
  输出为 errors.csv，包含所有原始字段
```

Claude Code 会读取 `data.json` 内容，理解数据结构，生成针对性的代码，直接在项目目录创建文件。

**Codex CLI 操作：**

```bash
cd ~/project
codex "读取 data.json，筛选 status=error 的记录，输出为 errors.csv"
```

Codex CLI 会在沙箱中执行，每一步操作前显示执行计划，确认后才写文件。

**结论：**
- 两者完成的结果相近
- Claude Code 更"沉浸"，对话式体验更流畅
- Codex CLI 的沙箱机制让每步操作更透明，安全感更强
- 对于新手，两者都可以作为起点；本课程后续示例以 Claude Code 为主

## 六、安装后的必做配置

无论选择哪款工具，完成安装后建议做这两件事：

### 6.1 创建项目级 AI 配置文件

在你的项目根目录创建 `CLAUDE.md`（Claude Code 读取）或 `.codex/instructions.md`（Codex CLI 读取），写入项目背景：

```markdown
# 项目说明

这是一个用 Python Flask 写的后端 API 项目。

## 技术栈
- Python 3.11
- Flask 3.0
- PostgreSQL 15
- SQLAlchemy

## 编码约定
- 所有 API 返回格式：{ "code": 0, "data": {}, "msg": "" }
- 数据库操作统一使用 ORM，不写裸 SQL
- 错误统一抛出 AppException

## 重要文件
- src/models/ 数据模型
- src/routes/ API 路由
- src/services/ 业务逻辑
```

有了这个文件，AI 每次都能快速理解你的项目背景，不用每次重复说明。

### 6.2 把 API Key 管理好

- 不要把 API Key 硬编码在代码里
- 不要提交 `.env` 文件（确保它在 `.gitignore` 中）
- 定期在控制台检查 API 使用量，设置消费上限

```bash
# .gitignore 中添加
.env
.env.local
```

## 本篇小结

- AI 编程工具分四类：IDE 插件、独立 AI IDE、CLI、网页生成型
- 新手推荐从 Claude Code 或 Bolt.new 入手，有经验的开发者选 Cursor
- **Claude Code** 安装：`npm install -g @anthropic-ai/claude-code` → 申请 Anthropic API Key → `claude` 启动

- 沙箱模式是 Codex CLI 的安全亮点，推荐日常使用
- 安装完成后记得创建项目级 AI 配置文件，让 AI 读懂你的项目
