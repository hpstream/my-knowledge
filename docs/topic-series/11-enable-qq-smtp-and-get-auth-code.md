# 第 11 篇｜QQ 邮箱怎么打开 SMTP？怎么拿到授权码？

> 适合人群：知道要用 QQ 邮箱发邮件，但在 QQ 邮箱设置里**找不到**「SMTP 在哪开」的人
> 目标：**5 分钟内拿到一串 16 位授权码**，复制到 `.env` 就能用
> 这一篇是 [《第 09 篇 QQ 邮箱 SMTP 接入》](./09-qq-mail-smtp-for-testing.md) 的**前置步骤**

---

## 先说结论

QQ 邮箱的 SMTP 服务**默认是关的**，所以你在邮件客户端里直接输 SMTP 密码一定连不上。

正确流程是：

```
1. 用网页登录 QQ 邮箱 mail.qq.com
2. 设置 → 账户 → 找到 "POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务"
3. 点开启 → 用手机短信验证一次
4. 拿到一串 16 位授权码（一次性显示，赶紧复制）
5. 在你的 .env 里：SMTP_PASS=这串授权码
```

下面是每一步的截图位置和容易踩的坑。

## 1. 为什么要打开 SMTP？为什么要授权码？

> 👉 这部分属于基础认知的内容，09 篇 的第 1、2 节已经讲透了，可以搜索 [《第 09 篇 QQ 邮箱 SMTP 接入》](./09-qq-mail-smtp-for-testing.md) 的「SMTP 是什么？」和「为什么要用授权码」两节学习，这里不展开讲解。

简单一句话：
**QQ 密码 ≠ 授权码**。授权码是 QQ 给"程序代发邮件"专门发的一串临时凭据。

---

## 2. 开启 SMTP 的 5 步操作

### Step 1. 用电脑浏览器登录 mail.qq.com

⚠️ 必须是**网页版**。手机 QQ 邮箱 App 里现在已经看不到这个开关入口了。

打开 [https://mail.qq.com](https://mail.qq.com)，扫码或账号密码登录。

### Step 2. 进入「设置 → 账户」

页面右上角能看到 **「设置」** 链接（齿轮图标旁边），点进去。
然后在设置页顶部 tab 里选 **「账户」**。

### Step 3. 找到这一节

往下滚，找到这一段标题：

> **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务**

这一节里会列出 5~6 个服务的开关。你需要的是其中两个：

- ✅ **IMAP/SMTP 服务**（推荐打开这个，比 POP3 灵活）
- ⚪ POP3/SMTP 服务（可选，老协议，不开也行）

点 **「开启」** 按钮。

### Step 4. 用手机短信验证身份

这一步 QQ 会要求你给一个固定号码（通常是 `1069007xxxx` 这种）**发一条指定内容的短信**，类似：

```
配置邮件客户端
```

**几个关键点**：

- **必须用你 QQ 绑定的那个手机号**发，别人帮你发不行。
- 短信内容**严格照抄**网页上显示的那句话，不要加标点、不要改大小写。
- 发完之后**别关那个网页**，回到网页点「我已发送」就行。

发短信运营商可能收 0.1 元短信费（不是 QQ 收的）。

### Step 5. 拿到 16 位授权码

短信验证通过的同时，网页上**会一次性弹出**这串授权码，长这样：

```
abcdwxyzefghijkl
```

或者类似 16 个小写字母组成的字符串。

⚠️ **就显示这一次**。关掉网页就再也看不到了，只能重新生成。
🔒 **不要截图发到外网/聊天群**——它等同于你的"程序用专用密码"。

立刻打开你的项目，把它贴进 `.env.local`（或者线上环境变量）：

```env
# .env.local
MAIL_DRIVER=smtp
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=你的qq号@qq.com
SMTP_PASS=abcdwxyzefghijkl   # ← 刚才那 16 位
MAIL_FROM=你的qq号@qq.com
```

> 👉 这几个环境变量在代码里是怎么用的，可以搜索 [《第 09 篇 QQ 邮箱 SMTP 接入》](./09-qq-mail-smtp-for-testing.md) 的「配置 .env」一节学习，这里不展开讲解。

## 3. 验证 SMTP 真的开通了

最快速的两种验证方法，挑一个就行：

### 方法 A：直接跑项目（推荐）

```bash
# 1. 把上面那段配置写到 .env.local
# 2. 重启服务
pnpm dev

# 3. 浏览器打开 http://localhost:3000，点登录，输入任意你的邮箱
```

看终端日志，**没有报错** + **你的收件箱里能收到一封 「你的超级个体登录验证码：xxxxxx」** = 成功。

### 方法 B：用 swaks 命令行打一次

如果不想跑全套服务，单独验证 SMTP 这一段：

```bash
# macOS 安装
brew install swaks

# 用授权码登录一次
swaks \
  --to 你自己另一个邮箱@example.com \
  --from 你的qq号@qq.com \
  --server smtp.qq.com:465 \
  --tls-on-connect \
  --auth-user 你的qq号@qq.com \
  --auth-password 刚才的16位授权码 \
  --header "Subject: smtp test" \
  --body "if you see this, smtp works"
```

输出最后一行有 `250 OK` = 成功，发到对方邮箱了。

## 4. 常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| 在手机 App 里翻不到开关 | 设置里就是没有 SMTP 选项 | **必须用网页版** mail.qq.com，App 里没有 |
| QQ 提示「该账号未绑定手机号」 | 没法发验证短信 | 先去 [QQ 安全中心](https://aq.qq.com) 绑定手机号 |
| 短信发出去 1 分钟还显示「未收到」 | 网页等不到验证回执 | 发的内容必须**严格一字不差**，特别注意大小写和标点 |
| `SMTP_PASS` 填了 QQ 登录密码 | nodemailer 报 `535 Login Fail` | 永远填**授权码**，不是 QQ 密码 |
| 复制授权码时带了空格 | `535 Login Fail` 但密码看着对 | 重新复制；可以先粘到记事本里看看有没有不可见空格 |
| 服务一直能用，某天突然失效 | 之前一直正常，今天开始 `535` | QQ 会主动失效授权码（改密码 / 新设备登录都会触发），重新生成一次即可 |
| 开了 SMTP 但还是被退信 | nodemailer 没报错但对方收不到 | 不是 SMTP 没开的问题，是发件失败。可以搜索 [《第 10 篇 QQ SMTP 晚上不发邮件》](./10-qq-smtp-night-not-sending.md) 的排查 5 步法，这里不展开讲解 |

## 5. 如果你需要重新生成授权码

授权码**关掉网页就再也看不到了**，但你可以随时再生成一串新的：

1. 同样路径：`mail.qq.com` → 设置 → 账户 → POP3/IMAP/SMTP 服务
2. 找到 **「生成授权码」** 按钮（开启状态下就会出现）
3. 重复一次短信验证
4. 旧的授权码**同时失效**，新的填到 `.env` 里覆盖

什么时候要重新生成：

- 旧授权码丢了
- 改了 QQ 密码
- 在新设备登录过 QQ
- 怀疑授权码被别人拿到了

## 一句话总结

> 想用 QQ 邮箱程序化发邮件，**SMTP 服务默认关，需要在网页版手动开**。
> 开启过程会给你一串 16 位授权码——**只显示一次，立刻复制到 `.env` 的 `SMTP_PASS`**。
