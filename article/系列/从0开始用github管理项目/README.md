# 系列｜从 0 开始用 GitHub 管理你的第一个项目

> 系列定位：免费入门系列
> 适合人群：第一次接触 GitHub / Git，想把自己的项目放到云上的人
> 完整阅读时长：约 40 分钟
> 系统：Mac 主线（Windows 在文章里有对照）

---

## 这个系列你会完成什么？

跟完这 4 篇，你会拥有：

1. 一个自己的 GitHub 账号
2. 一个属于你的 GitHub 仓库
3. 一台已经装好 Git 的电脑
4. 一整套把代码推上 GitHub 的能力

也就是说，**你会拥有"用 GitHub 管理项目"这件事的最小完整闭环**。

后面所有跟"部署、AI 编程、自动发布"相关的事情，都是从这一步开始的。

---

## 适合谁？不适合谁？

### 适合
- 完全没接触过 GitHub 的人
- 听过 Git 但一直没装过的人
- 想做自己的网站 / 产品 / 项目，但不知道从哪开始的人

### 不适合
- 已经能用 `git clone / git push` 走完日常的人（你已经会了，不需要这套）
- 想直接学分支 / PR / 协作的人（那是后续系列的范围）

---

## 系列大纲

按顺序看，效果最好。每一篇都建立在前一篇基础上。

### [第 01 篇｜如何注册 GitHub](./01-如何注册-github.md)
- 目标：完成 GitHub 账号注册并能正常登录
- 大纲：
  1. GitHub 是什么、为什么后面一定会用到
  2. 打开官网开始注册
  3. 邮箱 / 密码 / 用户名怎么填
  4. 完成人机验证 + 邮箱验证
  5. 以后怎么重新登录 GitHub

### [第 02 篇｜从 0 开始建立一个仓库](./02-从0开始建立一个仓库.md)
- 目标：在自己的 GitHub 账号下创建第一个仓库
- 大纲：
  1. 仓库是什么
  2. 进入"新建仓库"的入口
  3. 仓库名 / 描述 / public-private 怎么选
  4. README / .gitignore / license 要不要勾
  5. 创建完成后会看到什么

### [第 03 篇｜如何安装 Git](./03-如何安装git.md)
- 目标：在自己电脑上装好 Git
- 大纲：
  1. Git 和 GitHub 是什么关系
  2. 下载 Git（Mac 主线 + Windows 对照）
  3. 用 `git --version` 确认装好
  4. 第一次必做的两条 `git config`

### [第 04 篇｜拉代码、关联仓库、提代码](./04-拉代码和提代码.md)
- 目标：跑通 clone / commit / push 完整闭环
- 大纲：
  1. 看懂 Quick setup 那一页的 3 块红框
  2. 情况一：直接 clone
  3. 情况二：从 0 起新项目并关联
  4. 情况三：本地已有文件夹关联仓库
  5. 日常改代码的三连命令
