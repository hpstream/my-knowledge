## 先说清楚：为什么你后面一定会用到 GitHub？

你后面学：

- 新建项目
- 保存代码
- 部署网站
- 和 AI 一起写代码
- 让 Vercel / Cloudflare 自动发布

几乎都离不开 GitHub。

你可以先把它理解成：

> **一个专门存放你项目代码的地方。**

以后你的网站代码、配置文件、文章内容，很多都会放在这里。

所以这一步别跳。

---

## 第 1 步：打开 GitHub 官网

打开这个网址：

```text
https://github.com
```

如果你看到首页上有 **Sign up** 按钮，就说明你来对地方了。

可以对照截图：
- `screenshot-20260609-093759.png`

操作：

1. 打开 GitHub 官网
2. 点击右上角 **Sign up**

---

## 第 2 步：输入你的邮箱

进入注册页后，GitHub 第一步通常会先让你输入邮箱。

可以对照截图：
- `screenshot-20260609-093832.png`

操作：

1. 在输入框里填你常用的邮箱
2. 点 **Continue** 或按回车

### 邮箱怎么选？

建议你直接用：

- 平时最常登录的邮箱
- 后面你能正常收验证码、收通知的邮箱

不建议：

- 临时邮箱
- 不常用、以后可能忘密码的邮箱

因为后面 GitHub 会给你发验证邮件。

---

## 第 3 步：设置密码

GitHub 下一步会让你设置密码。

可以对照截图：
- `screenshot-20260609-093919.png`

操作：

1. 输入一个你以后能记住的密码
2. 再继续下一步

### 密码怎么设置比较稳？

建议：

- 至少 12 位
- 大小写字母 + 数字混合
- 不要用太简单的密码，比如 `123456`、`password` 这种

如果你怕忘，直接记到密码管理器里。

---

## 第 4 步：设置用户名

接下来 GitHub 会让你选一个用户名。

可以对照截图：
- `screenshot-20260609-093931.png`
- `screenshot-20260609-094007.png`

这个步骤很重要，因为：

> **你后面 GitHub 主页地址、很多仓库地址，都会带这个用户名。**

比如：

```text
https://github.com/你的用户名
```

### 用户名怎么取？

建议：

- 简单一点
- 好记一点
- 尽量用你长期愿意保留的名字

比如：

- `huangpeng`
- `peng-dev`
- `superpeng`

不建议：

- 太随意的名字
- 一堆看不懂的数字
- 以后你大概率会嫌弃的网名

如果 GitHub 提示这个用户名不能用，就换一个，直到它通过。

---

## 第 5 步：完成验证码 / 人机验证

GitHub 会要求你做一次验证，确认你不是机器人。

可以对照截图：
- `screenshot-20260609-094014.png`
- `screenshot-20260609-094114.png`

这一类验证通常是：

- 拖动滑块
- 点指定图片
- 做一个小拼图

操作：

1. 按页面提示完成验证
2. 验证通过后继续下一步

### 如果一直过不了怎么办？

先试这几个办法：

- 刷新页面重来一次
- 换浏览器
- 关闭翻译插件
- 如果开了代理，换一个网络再试

---

## 第 6 步：验证邮箱

注册流程里最关键的一步，就是**去邮箱收 GitHub 的验证邮件**。

可以对照截图：
- `screenshot-20260609-094122.png`
- `screenshot-20260609-094135.png`
- `screenshot-20260609-094148.png`

操作：

1. 打开你刚才填的邮箱
2. 找 GitHub 发来的验证邮件
3. 点里面的验证链接或输入验证码

### 收不到邮件怎么办？

按顺序查：

1. 垃圾邮件 / 广告邮件文件夹
2. 邮箱是不是填错了
3. 多等 1~2 分钟
4. 回 GitHub 页面点 **Resend** 重新发送

如果还是收不到，换一个邮箱重新注册，通常比死磕更快。

---

## 第 7 步：注册成功后，你会看到什么？

注册完成后，GitHub 通常会进入欢迎页或者首页。

可以对照截图：
- `screenshot-20260609-094216.png`

这时候你已经完成了最重要的一步：

> **你有 GitHub 账号了。**

但别急着关页面，建议你顺手把下面 3 件事做掉。

---

## 第 8 步：注册完成后，顺手做这 3 个基础设置

### 1）上传头像

原因很简单：
以后你创建仓库、提交代码、做项目时，这个头像会一直跟着你。

不一定非要正式头像，但至少换一个你能认出来的。

### 2）确认邮箱没问题

进 Settings 看一下，确认你刚注册用的邮箱是对的，而且能正常收邮件。

### 3）把用户名记住

因为你后面经常会用到：

```text
https://github.com/你的用户名
```

如果用户名都忘了，后面很多操作都会慢半拍。

---

## 这一步做完以后，下一步应该学什么？

注册完 GitHub 账号之后，下一步最自然的动作就是：

> **创建你的第一个仓库。**

你可以接着看这篇：

- [从 0 开始建立一个仓库](./02-从0开始建立一个仓库.md)

这里不展开讲，直接去下一篇继续操作就行。

---

## 小结

这篇你实际完成了 4 件事：

1. 打开 GitHub 官网
2. 用邮箱完成注册
3. 设置密码和用户名
4. 验证邮箱，拿到一个真正可用的 GitHub 账号

只要你已经能正常登录 GitHub，这一步就算完成了。
