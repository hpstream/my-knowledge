# physics_ammo_break.html｜Ammo Break：刚体碰撞和物体破碎

> 本地官方案例：[`physics_ammo_break.html`](../../cases/physics_ammo_break.html)  
> 本篇目标：学习 Ammo.js 如何处理刚体世界、碰撞接触点、冲击强度，以及如何把一个可破碎物体拆成碎块。

## 先从现实问题说起

现实里物体受到足够大冲击会碎裂，比如玻璃、墙体、石块。

普通刚体只能整体运动，不能自动知道什么时候该拆成碎片。

这个案例讲 Ammo 刚体碰撞和可破碎物体如何配合。

## 先把基础概念说清楚

- 刚体世界负责重力、碰撞和运动。
- `ConvexObjectBreaker` 负责把可破碎几何拆成碎块。
- 接触点和冲击强度用来判断是否超过破碎阈值。

## 这个技术解决什么

它适合爆破、破墙、碎石、破碎道具等效果原型。

破碎后，每个碎块都要重新成为物理世界里的刚体。

## 打开案例后看什么

- 看碰撞发生后，物体什么时候从整体变成碎块。
- 观察碎块如何重新加入物理世界继续运动。
- 理解渲染网格和物理刚体需要同步。

## 官网核心代码

```js
const convexBreaker = new ConvexObjectBreaker();

convexBreaker.prepareBreakableObject( object, mass,
  new THREE.Vector3(), new THREE.Vector3(), true );

physicsWorld.stepSimulation( deltaTime, 10 );

const debris = convexBreaker.subdivideByImpact(
  threeObject0, impactPoint, impactNormal, 1, 2
);
```

## 这段代码到底在做什么

- Ammo 负责真实碰撞，Three 负责把碰撞结果画出来。
- prepareBreakableObject 给 Three 网格附加可破碎信息：质量、速度、角速度和是否可破碎。
- stepSimulation 每帧推进物理世界，等于让物理引擎先算完位置、旋转和接触。
- 案例会读取碰撞 manifold，找到接触点、法线和冲击强度。
- 冲击超过阈值时，subdivideByImpact 按撞击点和撞击方向切分碎块。
- 碎块不是视觉假动画，而是新的物理刚体，会继续参与后续碰撞。
