# webgl_lights_spotlights.html｜Multiple SpotLights：多盏聚光灯的组合效果

> 本地官方案例：[`webgl_lights_spotlights.html`](../../cases/webgl_lights_spotlights.html)  
> 本篇目标：学习多盏 SpotLight 如何共同照明，以及为什么多阴影光源会带来明显性能成本。

## 先从现实问题说起

真实舞台或展厅不会只有一盏灯。多盏聚光灯叠加后，颜色、阴影、性能都会变复杂。

新手常见问题是：灯越加越多，画面过曝，阴影变慢，调试时也不知道哪盏灯在影响哪里。

这个案例讲的是多盏 SpotLight 的组合和成本。

## 先把基础概念说清楚

- 每盏 SpotLight 都有自己的颜色、位置、方向、光锥和阴影。
- 开启阴影的灯通常需要额外渲染阴影贴图，多盏灯成本会明显上升。
- helper 可以帮助你看每盏灯的方向和范围。

## 这个技术解决什么

当你做舞台、展馆、游戏场景局部照明时，需要管理多光源的主次关系。

这个案例让你同时关注效果和性能，而不是无脑加灯。

## 打开案例后看什么

- 关掉其中一盏灯，看画面主次光如何变化。
- 观察彩色灯叠加后材质颜色怎么变。
- 注意多盏 castShadow 灯对性能的影响。

## 官网核心代码

```js
const newObj = new THREE.SpotLight( color, 10 );
newObj.castShadow = true;
newObj.angle = 0.3;
newObj.penumbra = 0.2;
newObj.decay = 2;
newObj.distance = 50;
```

## 这段代码到底在做什么

- 这个案例适合理解“灯光组合”，不是只看单盏灯参数。
- 多盏灯颜色混合后，物体颜色会被改变。
- 每个开启阴影的 SpotLight 都需要额外渲染阴影贴图。
- 在真实项目里，通常只让少数关键灯投影，其他灯只照明。
- 多灯布光要配合曝光和 tone mapping，否则容易过曝。

## 本案例参数字典

这里只解释官网核心代码里最关键的参数，通用的相机、renderer、resize、DOM 事件等样板参数不在每篇里重复。

| 代码片段 | 参数 | 含义 |
|---|---|---|
| `new THREE.SpotLight( color, 10 )` | `第 1 个参数：color` | color：聚光灯颜色。 |
| `new THREE.SpotLight( color, 10 )` | `第 2 个参数：10` | intensity：聚光灯强度。 |
| `newObj.castShadow = true` | `castShadow` | 是否投射阴影。 |
| `newObj.angle = 0.3` | `angle` | 聚光灯光锥开口角，数值越大照亮范围越宽。 |
| `newObj.penumbra = 0.2` | `penumbra` | 聚光灯边缘软化比例。 |
| `newObj.decay = 2` | `decay` | 灯光距离衰减系数。 |
| `newObj.distance = 50` | `distance` | 光照影响距离或控制距离。 |

## 参数和观察方法

| 你操作什么 | 重点观察什么 |
|---|---|
| 关闭其中一盏灯 | 观察主次光变化 |
| 关闭部分阴影 | 性能改善但阴影减少 |
| 修改颜色 | 观察彩色光混合 |
| 打开 helper | 逐盏校准方向 |
